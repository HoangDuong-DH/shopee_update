# ListingStudio — release 06 October 2026

This release combines session continuity, portable setup/transfer and the tested reliability fixes in the working application.

- Database pool failures and response deadlines no longer leave unbounded queries or unhandled idle-error exits. Unknown mutations are never automatically replayed.
- Product lists use bounded SQL paging and exact source/revision restoration.
- Source imports use bounded bytes, parser threads, lease fencing and a 120-second parser deadline. Compiled worker dependencies are checked independently of TypeScript loaders.
- Nest 12.1.2 and its lockfile address the audited advisories; isolated production audit reported zero vulnerabilities.
- Owned-process supervision bounds API/web recovery and holds worker recovery for queue review.
- Explicit connection renewal is independent of paused publishing, survives owned API recovery and remains disabled in new setup/transfer/isolated mode until permitted.
- Scoped feature docs, context checkpoints and verified context transfer support continuation without loading all history.

Verification: typecheck/build; 2,942 unit/integration coverage with four full-run timeouts subsequently passing in the complete 61-case affected-suite rerun; actual intake/workspace/recovery browser cases; onboarding/supervisor/maintenance checks and isolated five-minute load acceptance with 32,544 requests and no failures. See PROJECT_HANDOFF for the exact limits. Combined evidence is not a claim that every suite passed in one run or that all shops/categories and 24-hour operation were tested.

GitHub/source ZIP contain code and fixtures only. Current database, keys, source blobs, journals, reference library and session context are delivered separately through a private bundle with its own manifest and receipts.
