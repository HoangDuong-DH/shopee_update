# Kho nguồn và sao chép

Archive lưu snapshot listing gốc, tầng phân loại/model, giá/tồn, ảnh/video, thông tin chi tiết và vận chuyển. Bản sao dùng đúng snapshot/manifest, scope shop đích và phiên nguồn; không dùng tên hay số lượng link để chứng minh mọi trường đã giữ.

ID item/model/kho/khuyến mãi thuộc shop; không chuyển nguyên ID bằng cách sửa nhãn. Dùng capability/metadata đích và báo ngoại lệ. Dedupe ảnh/blob theo nội dung giúp tốc độ/dung lượng, vẫn giữ provenance và thứ tự/vai trò ảnh.

Sao chép là phạm vi riêng với đăng ẩn, mở bán hoặc thay bìa. Unknown phải đối chiếu receipt/readback, không tạo thêm bản sao. Checkpoint giúp tìm snapshot và batch, không thay thế DB hoặc đọc lại cần thiết trước ghi.
