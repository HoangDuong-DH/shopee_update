# Chuẩn bị listing

Bản chuẩn bị nối đúng nguồn đã duyệt với metadata/capability của shop và ngành hàng đích. Chỉ điền giá trị từ nguồn hoặc schema đã xác nhận; không tự tạo lựa chọn để vượt validation.

Các thay đổi cấu trúc/tên lựa chọn phải làm mới mapping SKU và giá theo đúng source revision. Preflight server kiểm các thiếu sót trước execution. Draft/prepared snapshot không tự tạo listing; quyền chuẩn bị khác quyền đăng.

Phát hiện thiếu nguồn hoặc metadata thì giữ riêng bộ và báo phần cần bổ sung. Giao diện phải chỉ ra thao tác tiếp theo theo sản phẩm, không bắt người dùng đọc toàn bộ JSON hoặc diagnostic kỹ thuật.
